# File Converter Pro クイックスタート

## インストール

1. `release` フォルダーを開きます。
2. 最新のインストーラー（例: `File Converter Pro Setup 1.0.2.exe`）を実行します。
3. Windows のインストール手順に従います。
4. スタートメニューまたはショートカットから File Converter Pro を開きます。

完全な `.exe` インストーラーを使用してください。`.blockmap` と `.__uninstaller.exe` はインストーラーではありません。

## 5つの手順

1. `File Converter Pro` を起動します。
2. `Browse Files` または `Browse Folder` をクリックします。
3. 希望する出力形式を選択します。
4. `Convert All` をクリックします。
5. `Download` をクリックして結果を保存します。

設定で出力フォルダーを指定すると、ダウンロードは Windows の保存ダイアログを開かずに自動的にそこへ保存されます。出力フォルダーを指定しない場合は、Windows が保存場所を確認します。出力フォルダーがなくても変換できますが、ソースファイルは自動的に削除されません。

## 暗号化された保管庫

1. 設定を開き、出力フォルダーを選択します。
2. 「出力フォルダーを保管庫として設定」を有効にします。
3. 10 文字以上のパスワードと容量上限を設定します。
4. ZIP のエクスポート時に保管庫を保存先として選択します。
5. 設定から保管庫を開き、ZIP をエクスポートまたは削除します。

保管庫のファイルは暗号化された `.fcpv` コンテナーです。Windows エクスプローラーでは内容を読み取れません。パスワードは保存されないため、パスワードなしではファイルを復元できません。

ファイルをウィンドウへドラッグして追加することもできます。

## 音声の文字起こし

音声ファイルを追加し、テキストには `TXT`、字幕には `SRT` を選択して `Convert All` をクリックします。Whisper はインストーラーに含まれ、ローカルで実行されます。MSYS2 やインターネット接続は不要です。WAV ファイルは自動的に正規化されます。

## 重要

アプリは変換を開始するときに、各ソースファイルが元の場所にあり、引き続きアクセスできるかを確認します。ファイルが削除、移動された場合、またはアクセスできない場合はエラーメッセージが表示され、そのファイルの変換は続行されません。他のファイルの変換は通常どおり続行されます。

## 簡単なヒント

- 有効で破損していないソースファイルを使用してください。
- 目的に合った解像度を選択してください。
- 大きな動画や音声ファイルは処理に時間がかかる場合があります。
- 複数の結果を ZIP ファイルとしてまとめてダウンロードできます。
- `F11` で全画面表示を切り替えられます。

ファイルはローカルで処理され、アップロードされません。

## 背景

歯車アイコンをクリックし、設定で `背景を追加` または `背景を変更` を選択します。`背景をオフ` でデフォルトの背景に戻ります。画像が引き伸ばされないよう、画面と同じアスペクト比の画像を使用してください。
